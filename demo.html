Подстановка — полные примеры

Все возможные варианты: формулы, пустые ячейки, текст vs числа, отсутствие строк

Правила работы

  • Формулы защищены — ячейки с формулами в получателе никогда не перезаписываются (проверка HasFormula)
  • Пустой источник пропускается — если ячейка в источнике пуста, ячейка получателя не затирается (IsSourceEmpty)
  • Числа только — режимы Минимум, Максимум, Сумма работают только с числами; текстовые ячейки не затрагиваются
  • Уникальные строки — строка А006 есть только в получателе и не трогается (кроме режима Добавить, который добавляет отсутствующие строки из источника)
  • Ключевые столбцы не перезаписываются — столбец «Артикул» используется только для поиска совпадений

Заменить все совпадающие ячейки значениями из источника

АртикулНаименованиеЦенаКол-во

А003Товар В источн. пуст150 —10 источн. пуст

А006Товар Е нет в источн.600—
А001 — формула защищена. А003 — пустой источник не затирает получатель. А006 — нет в источнике, не трогается.

Пустые rcEmpty

Заполнить только пустые ячейки получателя

АртикулНаименованиеЦенаКол-во
А001Товар А=B1*25
А002Товар Б2503 —
А003Товар В источн. пуст150 —10
А004Товар Г2801
А006Товар Е нет в источн.600—
Заполняются только ячейки которые были пустые в получателе И непустые в источнике. А004 — все заполнены, без изменений.

Минимум rcMin

Оставить наименьшее значение (только числа)

АртикулНаименованиеЦенаКол-во
А001Товар А текст=B1*25
А002Товар Б текст200 min(250,200)3 —
А003Товар В источн. пуст150 —10 источн. пуст
А004Товар Г текст2801
А006Товар Е нет в источн.600—
А004: min(280,300)=280 и min(1,2)=1 — получатель уже меньше, без изменений. Текстовые столбцы не затрагиваются.

Максимум rcMax

Оставить наибольшее значение (только числа)

АртикулНаименованиеЦенаКол-во
А001Товар А текст=B1*25
А002Товар Б текст2503 —
А003Товар В источн. пуст150 —10 источн. пуст
А004Товар Г текст300 max(280,300)2 max(1,2)
А006Товар Е нет в источн.600—
А002: max(250,200)=250 — получатель больше, без изменений. А004: оба значения меньше в источнике — заменяются.

Добавить rcAdd

Только добавить отсутствующие строки из источника (существующие не трогать)

АртикулНаименованиеЦенаКол-во
А001Товар А=B1*25
А002Товар Б250—
А003Товар В—10
А004Товар Г2801
А006Товар Е нет в источн.600—
А005—400—
А005 добавлена из источника (ключ отсутствовал в получателе). Существующие строки не изменяются. А006 не удаляется.

Сумма rcSum

Сложить значения источника и получателя (только числа)

АртикулНаименованиеЦенаКол-во
