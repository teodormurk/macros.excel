Compare Mode (rcCompare)

Fill empty + add missing rows, with color-coded marking of differences

RED — Source: missing in dest / dest was empty
GREEN — Dest: new row added
YELLOW — Dest: values differ
ORANGE — Dest: empty cell filled from source

Compare Rules

  • Missing row — key exists in Source but not in Dest: mark Source cells RED, add row to end of Dest with GREEN
  • Empty dest cell — same key, Dest cell is empty: mark Source cell RED, fill Dest cell and mark ORANGE
  • Different values — same key, both have values but they differ: mark Dest cell YELLOW (no replacement)
  • Same values — no change, no marking
