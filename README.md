# macros.excel

VBA-модули для надстройки **Подстановка** — подстановка данных между листами по ключевым столбцам.

## Первая установка

```bash
git clone https://github.com/teodormurk/macros.excel.git
cd macros.excel
```

Положите `Книга1.xlsm` рядом с `update.py` и выполните:

```bash
python3 update.py
```

> **Примечание:** Ribbon XML (вкладка «Подстановка») нужно добавить вручную через [Office RibbonX Editor](https://github.com/fernandreu/office-ribbonx-editor/releases) один раз.

## Обновление модулей

```bash
cd macros.excel
git pull
python3 update.py
```

## Структура

```
modules/
├── ModSubstCore.bas      — логика подстановки
├── ModSubstUtils.bas     — утилиты, двойной клик, восстановление
├── ModSubstUI.bas        — обработчики ленты
└── ThisWorkbook.cls      — инициализация, события книги
```

## Как пользоваться

1. **Назначить листы** — кнопки «Лист-источник» / «Лист-получатель» на ленте
2. **Назначить столбцы** — выделить столбцы → кнопка «Ключ» / «Источник данных» / «Получатель данных»
   - Или двойной клик на ячейку заголовка
3. **Выполнить** — выбрать режим и нажать кнопку

Цвета заголовков: зелёный — источник, синий — получатель, жёлтый — ключ.
